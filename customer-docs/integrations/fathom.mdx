Connect Fathom when it is one of your meeting recording sources. You paste one API key. Ergo sets up the webhook for you.

## Who can use this

- People with a **Standard** seat. Each person connects their own account.
- This is a personal connection. It is not an organization connection.

## Before you start

- Make an API key in your Fathom API settings.
- Use one notetaker for each person. While Fathom is connected, you cannot connect Ergo Notetaker, Ergo Desktop Notetaker, Granola, Gong, Fireflies, Circleback or BlueDot. Ergo shows **Disconnect Fathom first**.

## Steps

1. In Fathom, open your API settings and make an API key.
2. In Ergo, open **Settings → User integrations**. In **Note takers**, find **Fathom** and click **Connect**.
3. In the **Connect Fathom** window, paste the key in **API Key**. Click **Connect**.
4. Make sure that the row shows **Disconnect**.
5. Record one new meeting in Fathom.
6. After Fathom completes the recording, look for the meeting in **Meetings**.

## What to expect

- You do not copy a URL or a secret. Ergo checks the key and makes the Fathom webhook itself.
- The connection brings in only new recordings.
- To bring in past Fathom meetings, use **Meeting backfill → Fathom** on the same page. The window is **Import historical Fathom meetings**.

## Common issues

- The connect fails with a message that the webhook registration failed: click **Connect** again. If it fails again, make a new API key in Fathom.
- The API key is not valid: copy it again from Fathom.
- **Disconnect Fathom first** shows on another notetaker: Fathom is connected. Disconnect it first.
- Two sources recorded one meeting: see [Using multiple notetakers with Ergo](https://support.joinergo.com/articles/3534048190).
- A meeting is not processed: see [Meeting processing time and status states](https://support.joinergo.com/articles/3507520478).
