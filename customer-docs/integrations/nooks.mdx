Connect Nooks so that Ergo receives your calls. One connection serves the whole organization. It uses a webhook URL from Ergo and a signing key from Nooks.

## Who can use this

- The organization **Owner** and team **Admins**.

## Before you start

- Make sure that you can make webhooks in Nooks.

## Steps

1. Sign in to Ergo as the Owner or a team Admin.
2. Open **Settings → Org integrations**. In **Dialers**, find **Nooks** and select **Connect**.
3. In the dialog **Nooks Dialer**, select **Copy** next to **Webhook URL**.
4. In Nooks, go to the webhook settings (the **Webhooks** page under the Nooks integrations). Make a webhook for the event **call.logged**, paste the URL, and save it.
5. Copy the signing key that Nooks shows after the save. Nooks shows it one time.
6. In Ergo, paste the key in **Webhook signing key** and select **Save setup**.
7. Make sure that the dialog shows **Active** and that the **Nooks** row shows the label **Connected**.
8. Make one test call.

## What to expect

- The signing key starts with `nooks-webhook-signing-key-`. Ergo accepts only a key with this start.
- A new key replaces the old key for the organization.
- The **Nooks API key** row in **Meeting backfill** is a different connection. It imports past calls only.

## Common issues

- Ergo does not accept the key: the key does not start with `nooks-webhook-signing-key-`. Check that you copied the whole key.
- You lost the key: make a new webhook in Nooks to get a new key. Then save it in Ergo.
- The dialog shows **Not connected**: save the signing key again.
