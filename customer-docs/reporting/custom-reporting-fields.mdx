Custom reporting fields define what Ergo can analyze and chart. Make each field clear. Unclear fields make unclear dashboards.

## Who can use this

- Users with Reporting create access can manage custom fields.
- The Owner or an Admin of any team can write fields for all teams. Other users with create access can write fields only for their own teams.

## Steps

1. Select **Reporting** in the left navigation.
2. Select the **Custom Fields** tab.
3. In **Org Reporting Fields** (all teams) or **<Team name> Reporting Fields**, select **Create**.
4. Enter the **Field Name**. Do not use a period. You cannot change the name later.
5. Select the **Type** (**Sentence** or **Picklist**) and the **Dialog Focus** (**Customer**, **Sales Rep**, or **Both**).
6. Enter the **Description**. For a picklist, add the **Picklist Options**.
7. Optional: open **Advanced Settings** and add up to 10 meeting-title phrases. Ergo then fills the field only for meetings whose title has one of the phrases. Leave the list empty to include all meetings.
8. Select **Save**. Ergo also saves the field when it has a name and a description.

To add fields that Ergo supplies, select **Add Default** in the same section.

## Picklist options

- To add many options, select **Upload CSV**. Or paste a list (commas or new lines) and select **Add options from list**.
- Ergo ignores options that the field has already.
- A picklist field must have one option or more.
- To group picklist values, turn on **Legacy view** → **Create New Report**. Select the pencil icon (**Configure picklist options**) on the field. The icon shows only on a field that has option groups.
- For competitors, use the default field **Competitors Mentioned**. Edit it and enter each competitor one time, with one spelling.

## Get a draft from Ergo

- Select **Ask Ergo** in the corner of the **Description** box.
- Ergo opens the agent panel with a request that you can send. Or it opens **Ask Ergo to write this field**.
- In that dialog, describe what you want to track. Select **Generate Field**, then **Apply Suggestions**.
- Examine the result before you use the field.

## What to expect

- The **Type** list has **Sentence** and **Picklist** only. A numerical field stays available only if your organization made it before.
- You cannot change a field name after Ergo saves the field. To use a different name, delete the field and create a new one.
- Ergo fills a field when it processes a meeting. A new field has data only for meetings that Ergo processes after you create it.
- Reporting has no control to fill older meetings. If you need older data, ask Ergo support before you promise a historical report.
- Ergo makes reporting data from meetings, not from email threads.
