An agent report sends a recurring summary by email. It uses the reporting fields and the analysis instructions that you choose.

## Who can use this

- Only the organization **Owner** and team **Admins** see the **Agent Reports** tab.
- Recipients can be organization members or external email addresses.

## Steps

1. Select **Reporting** in the left navigation, then the **Agent Reports** tab.
2. Select **New Report**.
3. In **Setup**, enter the **Name** and the **Schedule** (**Day**, **Time**, **Timezone**). Select **Continue**.
4. In **Recipients**, select members, or enter an address and select **Add external**. Select **Continue**.
5. In **Fields**, select **Choose fields manually** (up to 10 fields or rubrics) or **Let Ergo choose automatically** (Ergo selects 3 to 5). Select **Continue**.
6. In **Analysis**, enter **Analysis instructions** (optional).
7. Keep **Enable agent report** on to send on the schedule, or turn it off.
8. Select **Create report**.

## Test a report

- **Test Run** and **Send Now** show only on a report that is **Enabled** and complete. First enable the report and save it.
- Select **Test Run**, select the test recipients, and send. Ergo sends a labeled test email only to those recipients.
- Select **Send Now** to send at once to the recipients of the report.
- For one report, you can start 7 test runs and 3 **Send Now** runs in 24 hours.

## What to expect

- To save without a schedule, select **Save draft**. Ergo saves the report as disabled.
- To change a report that exists, select **Save changes**.
- Manual field selection needs at least one field before you can enable the report.
- Recipient addresses must be valid. You cannot add the same address two times.
- A queued run is not a confirmed delivery. Check the run history for the result. See [Agent report run history](https://support.joinergo.com/articles/1660665197).
