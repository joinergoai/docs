Each saved chart shows on a Reporting dashboard. Use dashboards to keep your regular reviews in order.

## Who can use this

- Users with create access can save, edit, duplicate, move, and delete charts.
- Without create access, the **⋯** menu on a chart has only **Show values as**, **Download CSV**, and **Download image**.

## Before you start

- The dashboard must exist before you save to it. To make one, select **New dashboard** on the **Dashboards** tab.
- The save dialog cannot make a dashboard.

## Steps

1. Make the chart in the chart builder (**Create a chart**).
2. Select **Save chart**.
3. In **Save to a dashboard**, select the dashboard in **Dashboard**.
4. Select **Save chart**.

## Manage charts

The **⋯** menu on a chart has these actions:

- **Edit chart**. Use it also to rename the chart.
- **Duplicate**. This makes **Copy of <name>** on the same dashboard.
- **Move to dashboard…**
- **Download CSV**
- **Download image**
- **Delete chart**

To copy a chart to a different dashboard, select **Duplicate**. Then move the copy.

## Change the layout

1. Select the **⋯** menu next to the dashboard name.
2. Select **Arrange charts**.
3. Drag a chart to change the order.
4. Set each chart to **Half** or **Full** width.
5. Select **Save layout**.

## What to expect

- After you save a chart, Ergo opens the dashboard with the new chart.
- You cannot drag or resize a chart on the dashboard itself.
- Ergo saves nothing until you select **Save layout**.
- **Move to dashboard…** removes the chart from the old dashboard.
- Dashboard grants control who can see the target dashboard.
