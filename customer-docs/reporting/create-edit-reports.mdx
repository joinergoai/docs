A report is a chart on a Reporting dashboard. You build the chart in the chart builder. Then you save it to a dashboard.

## Who can use this

- Users with Reporting create access can create and edit charts.
- Users without create access can look at dashboards. They cannot see the creation controls.

## Before you start

- The dashboard must exist before you save a chart to it. See [Default dashboards](https://support.joinergo.com/articles/7968597484).

## Steps

1. Select **Reporting** in the left navigation.
2. On the **Dashboards** tab, select **Create a chart**.
3. Enter a name in **Chart name**.
4. Select a field in **Reporting field**.
5. Select the chart type in **Chart**: **Bars** (how often each one comes up), **Deal value**, **Over time** (by month), **Breakdown** (split by another field), or **Won vs lost**.
6. Open **Filters**. Set **Date range**, **Deal stage**, and other filters if necessary.
7. Examine the **Live preview**. Then select **Save chart**.
8. In **Save to a dashboard**, select the dashboard. Select **Save chart** again.

## Edit a chart

1. Open the dashboard that has the chart.
2. On the chart, select **⋯**.
3. Select **Edit chart**.
4. Change the settings.
5. Select **Save changes**.

## What to expect

- A chart field is a reporting field, a close reason, or a grading rubric. The label is **Grading rubric** for a rubric.
- CRM deal and company properties are available only as a breakdown or a filter.
- A grading rubric chart has no breakdown. Its filters are **Rep**, **Deal stage**, and **Deal value**.
- **Date range** options are **All time**, **Last 7 days**, **Last 30 days**, **Last 3 months**, **Last 6 months**, **Last 12 months**, and **Custom range**. An **Over time** chart does not offer **Last 7 days** and **Last 30 days**.
- To filter by deal amount, use **Deal value** (**Minimum** and **Maximum**) in **Filters**.
- There are no pie charts. A pie chart from the Legacy view shows as bars.
- After you save, Ergo opens the dashboard and shows the new chart. To make another chart, select **Create a chart** again.

## Common issues

- The dashboard is not in the save list: check your Reporting access and the dashboard permissions.
- There are no results: see [Search/reporting has no results](https://support.joinergo.com/articles/8146112124).
