Run history shows what happened when an agent report tried to make or send a report.

## Who can use this

- The organization **Owner** and team **Admins**. Only they see the **Agent Reports** tab.

## Steps

1. Select **Reporting** in the left navigation.
2. Select the **Agent Reports** tab.
3. Find the card of the report.
4. Select the latest run on the card (for example **Succeeded 2h ago**), or one of the squares below it.
5. Read the run details in the panel. To see a different run, select it below **Run history**.

## What to expect

- Run statuses are Queued, Running, Succeeded, Failed, and Skipped.
- Badges at the top show the status, the trigger (a scheduled run, a test run or a manual send), and the mode.
- The panel has these sections: **Lifecycle** (Created, Scheduled for, Started, Completed, Duration), **Report configuration** (Schedule, Fields, Field mode, Recipients, Analysis instructions), **Analysis**, **Charts**, and **Email** (Delivery, Recipients, Sent at).
- All the runs that you can start (scheduled, **Test Run**, **Send Now**) use the **Send** mode.
- A test run sends a labeled test email to the test recipients that you select. It does not go to the recipients of the report.

## Common issues

- A failed run shows a message in the **Lifecycle** section. For example: "The analysis failed before the report could be generated.", "A chart could not be rendered, so no email was sent.", or "The email could not be sent."
- Use the message to decide what to do. You can change the report, examine the data, try again later, or contact support.
- To try again, select **Send Now** on the report card. It shows only for an enabled report with no run in progress. You can use it 3 times for one report in 24 hours.
- No scheduled run: make sure that the report is enabled.
- A run is still Queued or Running: wait, then open the panel again.
- If analysis failed, make sure that the selected fields have recent data.
