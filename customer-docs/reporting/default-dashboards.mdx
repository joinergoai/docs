A default dashboard gives your team a starting set of charts. You do not need to build each chart by hand.

## Who can use this

- Anyone with Reporting access can view the dashboards that are visible to them.
- Users with create access can make a dashboard from a template.

## Before you start

- When Ergo turns on Reporting, your organization gets three dashboards: **Sales Default Dashboard**, **Customer Success Dashboard**, and **Product Dashboard**.
- Make a new dashboard only if you want one more copy from the same templates.

## Steps

1. Select **Reporting** in the left navigation.
2. Stay on the **Dashboards** tab.
3. Select **New dashboard**.
4. Enter a name in **Name**.
5. Below **Start from**, select a template: **Sales Default Dashboard**, **Customer Success Dashboard**, or **Product Dashboard**. The line below each template shows how many charts it adds.
6. Select **Create dashboard**.
7. Examine the charts before you share the dashboard.

## What to expect

- A template adds only the charts for which your organization has the reporting fields. The dialog shows the number, for example **Adds 4 of 6 charts**.
- To get the other charts, add the default fields first. Select **Custom Fields** → **Add Default**. Then create the dashboard.
- The **New dashboard** dialog has no team option.
- To change the order of the charts, select the **⋯** menu next to the dashboard name → **Arrange charts**. You cannot change the order of the dashboards in the default view.
- To add a chart that is not in the template, select **Create a chart**.
- A dashboard shows useful charts only when the data exists.
