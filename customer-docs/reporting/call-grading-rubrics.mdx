A call grading rubric is a set of scored criteria. Ergo grades calls against it. Managers can then see repeatable coaching data.

## Who can use this

- Users with Reporting create access can manage rubrics.
- A rubric applies to the whole organization or to one team.

## Steps

1. Select **Reporting** in the left navigation, then the **Call Grading** tab.
2. Below **Organization-wide rubrics** or below **<Team name> rubrics**, select **Create rubric**. To start from a template, select **Add template**.
3. In **Setup**, enter the **Rubric name**. The description is optional.
4. Optional: open **Advanced meeting-title filters** and add up to 10 phrases. Ergo then grades only calls whose title has one of the phrases.
5. Select **Continue**. In **Scoring**, add the fields and their scores (0 to 5) with labels.
6. Select **Continue**. In **Requirements**, write the requirements for each score.
7. Select **Continue**. In **Review**, correct the problems that Ergo shows.
8. Select **Create rubric**. For a rubric that exists, select **Save changes**.

## What to expect

- The rubric editor has no autosave. If you close the dialog before **Review**, Ergo does not save your changes.
- You cannot change the scope later. To use the rubric for a different team, select **Copy** on the rubric.
- In **Scoring**, each field needs a name, a description, and two or more scores. A score is a whole number from 0 to 5. Each score has a label.
- In **Requirements**, write 1 to 8 observable requirements for each score. Ergo gives the highest score for which the call meets all the requirements. If no score is fully met, Ergo gives the nearest score.
- The templates are **Universal Sales Call Scorecard**, **MEDDPICC Call Scorecard**, **SPICED Call Scorecard**, **BANT Qualification Scorecard**, and **Challenger Call Scorecard**.
- To get a draft, select **Generate draft** below **Start with AI** in the **Setup** step. Examine each field and each requirement before you save.
- Rubrics appear as chart fields (**Grading rubric**). A rubric chart has no breakdown. Its filters are **Rep**, **Deal stage**, and **Deal value**.

## See the grade of one call

1. Open the meeting.
2. Select the **Insights** tab.
3. Read the score of each rubric field with the evidence.
4. Change a score there, or select **Discard** to remove the evaluation.

## Common issues

- A rubric grades the wrong calls: change the meeting-title phrases.
- Look at the source evidence before you coach from a chart.
