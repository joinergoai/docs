One person can use only one notetaker type at a time. Two captures of one meeting can still happen. This article explains why and what to do.

## Who can use this

- Anyone who manages their own notetaker in **Settings → User integrations → Note takers**.

## Before you start

- You can connect **Ergo Notetaker** and **Ergo Desktop Notetaker** together.
- You cannot connect a third-party notetaker (Gong, Fireflies.ai, Circleback.ai, BlueDot, Grain or Fathom) while Ergo Notetaker or Ergo Desktop Notetaker is connected. The reverse is also true. Ergo shows "Disconnect {name} first".
- You can connect only one third-party notetaker at a time.
- Granola can run together with the Ergo notetakers only for some organizations.

## Steps

1. Open **Settings → User integrations**.
2. In **Note takers**, select **Disconnect** on the notetaker that you do not want.
3. Select **Connect** on the notetaker that you want.
4. To stop the Ergo bot for one meeting, open **Dashboard**. In **Upcoming Meetings**, set the toggle to **Bot won't join**.

## What to expect

- When the Ergo bot, the Ergo desktop app and Granola capture the same meeting, Ergo puts the captures together.
- **Meeting History** shows one row with an **N captures** chip. Select the chip to open each capture.
- The capture that Ergo uses has the **Primary** badge.
- Ergo runs your automations for one capture. If a later capture is much more complete, Ergo can run them again for that capture.
- Two people in one meeting can use different notetakers. Then the meeting has two captures.
- An upload is a second meeting in **Meeting History**. Ergo runs the automations for it only if you select **Push to CRM**.
- A note goes to the automations only if you select **Push Automation** on it. Then the note and the recording both run.

## Common issues

- Two drafts for one meeting: open **Meetings**, select the **N captures** chip, and write down the capture names, for example **Bot capture** and **Desktop capture**. Then select **Support** in the left navigation.
- Two rows for one meeting: remove the filters. If both rows stay, tell support.
- **Connect** does not change to **Connected**: disconnect the other notetaker first.
