**Time-Based Deletion** deletes meetings that are older than a number of days that you set. The setting applies to the whole organization.

## Who can use this

- Only the organization **Owner** sees this switch.

## Before you start

- Know that the deletion is permanent. You cannot restore a deleted meeting.

## Steps

1. Sign in to the web app as the Owner.
2. Open **Dashboard**.
3. In the **Upcoming Meetings** card, select the ⋮ button (**Calendar settings**).
4. Turn on **Time-Based Deletion**.
5. In **Delete after … days**, enter a whole number of days. The default is 14. The minimum is 1.
6. Wait for the confirmation message. The setting saves automatically.
7. Open the menu again. Make sure that the switch and the number of days are correct.

## What to expect

- There is no **Save** button. The switch saves at once. A change to the number saves after you stop typing.
- A message shows, for example "Time-based deletion enabled (14 day retention)".
- Ergo deletes only meetings that were recorded after you turned the setting on. Older meetings stay in **Meeting History**.
- If you turn the setting off and then on again, the start time moves to that moment.
- The desktop app does not show this menu.

## Common issues

- You do not see **Time-Based Deletion**: you are not the Owner.
- Old meetings stay: Ergo does not delete meetings that were recorded before you turned the setting on.
- A meeting is missing from **Meetings**: ask the Owner if **Time-Based Deletion** is on.
