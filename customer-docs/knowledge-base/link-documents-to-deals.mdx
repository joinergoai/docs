Link an artifact to a deal so that the file shows with the deal. Only artifacts can be linked. Knowledge Base documents cannot.

## Who can use this

- The creator of an artifact. Only the creator sees **Link to deals**.
- People who can edit CRM records, for the **Upload** button on a deal.

## Before you start

- Make sure that the artifact exists. See [Generated documents](https://support.joinergo.com/articles/8336238316).
- Know the deal name.

## Steps

1. Open **Search** (⌘K), type **Artifacts** and press Enter.
2. On the artifact, open the **⋯** menu and click **Link to deals**.
3. If you have more than one pipeline, select the pipeline.
4. Type the deal name in **Search deals by name...** and click the deal. Do this again for each deal.
5. Click **Save**.
6. Open the deal. The file is in the **Documents** section on the right.

## What to expect

- When you link a **Private** artifact to a deal, Ergo changes its sharing to **Organization**.
- You cannot set it back to **Private** while it is linked to a deal. Unlink it first.
- To add a file directly to a deal, open the deal. In **Documents** on the right, click **Upload**.
- To remove one link, open the deal. In **Documents**, open the **⋯** menu on the file and click **Unlink from deal**.
- To remove all links, open **Link to deals** on the artifact, remove each deal, then click **Save**.

## Common issues

- You do not see **Link to deals**: you are not the creator of the artifact.
- You cannot find the deal: select the right pipeline, or check the spelling.
- You want to link a Knowledge Base document: this is not possible.
