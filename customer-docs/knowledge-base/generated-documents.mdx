Ergo names these files **Artifacts**. An artifact is a file that Ergo made in a chat, for example a report, a deck or a sheet. Artifacts are separate from Knowledge Base files.

## Who can use this

- People with a Standard seat.

## Before you start

- Make a file in a chat with Ergo first. See [Chat with Ergo](https://support.joinergo.com/articles/2744746875).

## Steps

1. To see all artifacts, open **Search** (⌘K), type **Artifacts** and press Enter.
2. To see the artifacts of one chat, open the chat and click the **Artifacts** button at the top right.
3. Use **All** or **My Artifacts** to select whose files you see.
4. Use the file-type list to show one type. Type in **Search artifacts...** to find a file by name.
5. Open the **⋯** menu on an artifact to work with it.

## What to expect

- All users can **View** and **Download**.
- Only the creator of the artifact sees **Rename**, **Share**, **Link to deals**, **Open in chat** and **Delete**.
- **Private**: for the creator. The organization Owner, and an Admin of a team that the creator is in, can also open it.
- **Organization**: all users in your organization can find and open it.
- **Public link**: a person who has the link can view and download it. Ergo asks this person to confirm an email address with a code first.
- A Knowledge Base file gives Ergo reference context. An artifact is an output. Manage them separately.

## Common issues

- You cannot find an artifact: select **All**, and check the file-type list.
- You do not see **Share** or **Delete**: only the creator sees them.
- You cannot set an artifact to **Private**: it is linked to a deal. Unlink it first.
