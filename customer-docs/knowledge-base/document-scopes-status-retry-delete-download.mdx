Use the status of a Knowledge Base document to see if it is ready. Then retry, download or delete it.

## Who can use this

- People with a Standard seat.
- You can delete your own documents. Only team Admins can delete team documents. Only the Owner and Admins can delete organization documents.
- All users who can see a document can download it.

## Before you start

- Open **Settings → Knowledge Base**.
- Each document shows its status and these icons: view, download, edit summary, retry indexing and delete.

## Status labels

- **Uploading...**: the file is on its way to Ergo.
- **Processing...**: Ergo reads and indexes the file.
- No label: the document is ready. Your agents can use it.
- **Indexing failed**: Ergo could not index the file. Put the pointer on the label to see the cause.

## Steps

1. To retry a failed document, click the **Retry indexing** icon. Only a user who can manage the document sees this icon.
2. To download a document, click the download icon.
3. To delete a document, click the trash icon.
4. In the **Delete Document?** dialog, click **Delete**.

## What to expect

- Retry is available only for a document that shows **Indexing failed**.
- The deletion is permanent, and your agents stop using the document.
- Ergo removes the document from search, then deletes the file. If Ergo cannot remove the document from search, the document stays in the list. Try again.
- If there is no download icon, Ergo has no stored file for this document.

## Common issues

- A document stays on **Processing...**: wait, then reload the page.
- **Indexing failed** again after a retry: read the cause on the label. Upload the file again.
- You do not see the delete or retry icon: your role does not manage this document.
