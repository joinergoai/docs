Run History shows each run of your automations and what happened. Use it to check if a run worked.

## Who can use this

- The Owner and team Admins see all runs of the organization.
- Other users see runs that they own or that ran for them.

## Before you start

- Know the name of the automation and when it should run.
- Check if the run was scheduled or started by hand.

## Steps

1. Click **Automations** in the left navigation.
2. Open the **Run History** tab. Or, on the **My automations** tab, click **Previous runs** on an automation.
3. Use the lists **All automations** and **All statuses** to find the run.
4. Read the label of each run: **Queued**, **Running**, **Completed**, **Failed**, **No action needed**, **Canceled** or **Scheduled**. A sandbox run also has the label **Preview**.
5. Click the run. The dialog shows **Lifecycle** (when the run was created, started and completed) and **Output** (what Ergo sent, or the error).
6. To run a failed or completed run again, click **Run again** → **Run latest version**.
7. If there are more runs, click **Load more**.

## What to expect

- An automation row has no health indicator. To see if an automation works, click **Previous runs** and read the status of the latest runs.
- Open a run to follow it. The dialog updates until the run ends. To update the list, load the page again.
- For a failed run, **Output** shows the error.

## Common issues

- A run is still **Queued** or **Running**. The final result is not available yet.
- The run is **Scheduled**: it waits for its start time.
- The list shows the wrong automation: check the **All automations** list.
