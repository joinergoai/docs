Scheduled agent runs are now **Automations**. An automation can run an agent task on a schedule and send the result to Slack or email.

## Who can use this

- People with a **Standard** seat.
- Everyone can make automations for themselves (**Only me**). A team **Admin** can also make them for **A team** or the **Entire organization**.

## Before you start

- To send to Slack, connect the Slack workspace first (**Settings → Org integrations → Workspaces**).
- Write a prompt that can run without more questions.

## Steps

1. Click **Automations** in the left navigation.
2. On the **Gallery** tab, click **Create automation**. Or click **Use template** on a template.
3. In **When**, select **On a schedule**. Select the days, the **Time** and the **Timezone**.
4. In **What**, select **Agent task** and type the prompt. To send fixed text, select **Static message**.
5. In **Where**, select **Slack message** or **Send email**. Then select the channel, the teammate or the email addresses.
6. In **Who can manage this**, select **Only me**, **A team** or **Entire organization**.
7. Click **Create automation**. The automation is **Active** at once. To save it without a start, click **Save as draft**.
8. On the **My automations** tab, use the switch to pause or activate the automation.

## Test and run

- **Run sandbox** runs the automation now and shows the result. It sends nothing and changes no CRM records. It works for **Active**, **Paused** and **Draft** automations.
- **Run live now** is a real run, with the same effects as a scheduled run. It works only for **Active** automations.
- To see past runs, click **Previous runs** on the row, or open the **Run History** tab.

## What to expect

- Your organization shares one pool of agent automations. The pool size is the number of active Standard seats, to a maximum of 20. **Active**, **Paused** and **Draft** automations count. Daily briefings and **Static message** automations do not count.
- The top of the page shows **Org agent pool** with the number used.
- One automation has one destination.

## Common issues

- **Create automation** is off: a necessary field is empty. Read **What will run** in the **Summary** panel.
- **Organization agent automation limit reached**: pause or delete an agent automation, or use **Static message**.
- Slack delivery fails: connect the Slack workspace, and add Ergo to the private channel.
