Ergo Desktop records meetings from your computer. No bot joins the call. Install it and sign in before you rely on local recording.

## Who can use this

- Each person who wants to record with Ergo Desktop. Ergo Desktop is available for macOS.

## Before you start

- Make sure that you see the row **Ergo Desktop Notetaker** in **Settings → User integrations → Note takers**. If you do not, ask Ergo support to turn on Ergo Desktop for your organization.
- Use the same Ergo account that you use on the web.

## Steps

1. On the web, open **Settings → User integrations**. In **Note takers**, find **Ergo Desktop Notetaker** and select **Download**.
2. In the dialog **Download the Ergo Desktop app**, select **Download for macOS**.
3. Open the downloaded file. Drag **Ergo** to **Applications**. Start **Ergo**.
4. On the screen **Sign in to Ergo**, select **Sign in**. Your browser opens. Sign in with your Ergo account.
5. On the page **Sign-in complete**, select **Open Ergo**.
6. On the screen **Set Up Ergo Desktop**, grant **Microphone Access**, **Screen Recording** and **Accessibility**.
7. Select **Connect** next to **Desktop Notetaker Connected**.
8. Select **Restart Ergo**. Open the user menu at the bottom of the left sidebar. Make sure that it shows your email.

## What to expect

- By default, Ergo Desktop records video and audio of supported meetings. Ergo posts a recording disclosure in the meeting chat.
- To record audio only, open **Settings → Desktop app → Recording** in the desktop app. Turn off **Video recording**. Then you can also turn off **Recording disclosure**.
- You can use Ergo Desktop Notetaker and Ergo Notetaker together.
- Desktop recording does not remove your duty to follow recording consent rules.
- To test, select **Quick Note**, then **Record**. Speak for one minute and select **Stop recording**. Look at **Recent** on the home page. The row shows **Processing...**. If it shows **Processing failed**, select **Retry**.

## Common issues

- **Connect** does not change to **Connected**: you have Gong, Fireflies.ai, Circleback.ai, BlueDot, Fathom or Grain connected. Disconnect it in **Settings → User integrations** on the web.
- The browser does not open the app: select **Open Ergo** on the page. If the page shows **Sign-in link expired**, select **Sign in** in the app again.
- The app shows a different user than the web: sign out and sign in with the correct account.
