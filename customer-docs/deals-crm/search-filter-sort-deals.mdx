Use search, filters and sort to narrow the **Board** or **List**. Each built-in tab starts with filters.

## Who can use this

- Everyone who can open **Deals**. All seats can read the page.

## Before you start

- Connect your CRM. If the page shows **No CRM Connected**, ask an owner or team admin to connect it in **Settings → Org integrations → CRM**.

## Steps

1. Open **Deals** and select the pipeline.
2. Type 3 characters or more in **Search deals...**. Press / to go to the box.
3. Click **+ Filter** (or press F). Select a field, then set the value.
4. To use a mapped custom field, select it in the same list under **Custom Properties**.
5. In **List**, click a column header to sort.
6. In **Board**, use the sort menu next to the search box. Click the arrow to change the direction.
7. Click **Reset** to go back to the default filters of the tab.

## What to expect

- Search finds deals by deal name, company name, contact name or email, meeting title, and the text of emails.
- Filter fields: **Owner**, **Team**, **Stage**, **Stage Status**, **Amount**, **Close Date**, **Create Date**, **Health**, **Priority**, **Last Meeting**, **Latest Meeting Outcome**, **Last Email**, **Last Correspondence**, **Status** and **Company**.
- Sort menu in **Board**: **Last Correspondence** (default), **Deal Name**, **Amount**, **Close Date**, **Create Date**, **Health**, **Priority**, **Owner**.
- Preset filters: all built-in tabs start with **Owner** set to you. **High Priority** adds **Priority** Top 20% or VIP. **This Week** adds **Last Meeting** this week. **Follow Ups** accepts only the **Owner** filter.
- **Reset** shows after you change a filter, the sort or the search on a built-in tab.

## Common issues

- A deal is missing: clear the search box. Then look at the filter chips.
- The **Deals** tab is not unfiltered. It shows only your deals. Remove the **Owner** chip to see all deals in the pipeline.
- The wrong pipeline, or **Companies**, is selected.
